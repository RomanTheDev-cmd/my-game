Создаёт играбельную основу Godot RPG: две связанные локации, бой, русские меню, два независимых задания, карта, навигация противников, световой заряд, приготовление и применение настоев, опыт и навыки. Переходы сохраняют мир и показатели героя; сохранения v1/v2 мигрируют в v3. Добавлены предбоевые контрольные точки и постоянные настройки.

Проверено локально: 225 автоматических проверок, настоящий рендер интерфейсов и обеих локаций. Проверяются реальные физические столкновения, попадания, условия альтернатив, однократные награды, миграция и восстановление сохранений. Подготовлены GitHub Actions и проверки universal macOS-архива; результат CI отдельно не подтверждён.

Это ранняя версия. Запуск на целевом Mac, Retina, производительность и длительные сессии ещё требуют испытаний. Полный объём ТЗ не завершён; ограничения и дальнейшая работа — в ROADMAP.md и PROJECT_STATE.md. Сюжетные материалы в описание не включены.
