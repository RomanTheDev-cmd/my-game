Создаёт первую играбельную основу Godot-проекта: две связанные локации, бой в реальном времени, русский интерфейс, отдельные правила заданий, награда и восстановление после гибели. Переходы сохраняют состояние обеих локаций и показатели героя; сохранения v1 автоматически мигрируют в v2.

Проверено локально: импорт Godot 4.6.3, 109 автоматических проверок, рендер экранов, экспорт macOS universal и Linux, запуск Linux-сборки. macOS-архив проверен на целостность, игровой пакет и arm64/x86_64. Внутренние материалы и инструменты исключены из игровых пакетов.

Настроен GitHub Actions для тестов и тестовых macOS-артефактов. Результат CI ещё не подтверждён. Запуск на реальном Mac, Retina и производительность требуют отдельных испытаний. Это ранний этап разработки; невыполненные требования полного ТЗ перечислены в ROADMAP.md.
