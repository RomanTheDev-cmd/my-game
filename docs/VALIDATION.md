# Проверки версии 0.4.0

6 ноября 2026, облачная Linux x86_64, Godot 4.6.3 standard.

`bash tools/test.sh`: **298 проверок Godot, 0 отказов**, 17 наборов. Бой 6; сохранения 35; регионы 9; задания 22; игровой цикл 41; переходы 21; навигация 20; магия 12; предметы/магия 16; настройки 7; развитие 14; альтернативы задания 27; экипировка/торговля 15; торговля в сцене 16; типы врагов 7; исследование/награды 20; миграция экипировки 10.

Новые интеграционные проверки используют настоящие CharacterBody2D, стрелы, стены, блок, кнопки покупки/продажи/экипировки и дисковую запись. Проверены характеристики оружия, совместная защита доспеха/щита, отдельное владение, запрет продажи надетого/сюжетного, невозможность прибыли перепродажей и удалённой торговли. При заблокированной записи покупка и находка не изменяют прежнее состояние.

Проверены третья локация, достижимость привала и наград по маршруту, возвращение/повторный визит/загрузка, охрана и однократность награды. Миграция v3 сохраняет обучение/ранения/предметы, добавляет прежнее неявное снаряжение и не выдаёт ретроактивную награду повторно при загрузке v4. При летящей вражеской стреле сохранение не считается безопасным.

RED до реализации: покупка не передавала предмет и не списывала цену (две проверки). Отдельно воспроизведена обрезка уведомления после перестройки UI (две проверки вычисленного положения); исправлены anchor offsets, регрессии включены в полный прогон.

`python3 tools/audit_story.py`: внутренняя сценарная модель 26 узлов/557 достижимых состояний, без сюжетных тупиков по её условиям. Это не интегрированная кампания. `python3 -m unittest discover -s tests -p 'test_*.py'`: 6 проверок валидатора с повреждёнными графами, все проходят. Вывод не содержит сюжетной прозы.

`bash tools/import.sh`: реальный импорт пройден без ошибок. Отдельная проба с сообщением ошибки и кодом 0 отклоняется с кодом 1; CI использует этот wrapper. Коды самого Godot сохраняются через pipefail.

`godot --headless --export-debug macOS build/Airvel-macOS.zip`: выполнено. `tools/verify_macos.py` подтверждает целостность ZIP, пакет и arm64/x86_64.

`godot --headless --export-debug Linux build/Airvel-Linux.x86_64`: выполнено; экспортированная игра запускается headless без ошибок.

`tools/verify_pack.py` для обеих платформ: 82 записи в каждом PCK, перевод и лицензия шрифта присутствуют. Сценарные материалы, документы, тесты, инструменты и build не включены.

`DISPLAY=:99 bash tools/capture.sh`: реальные рендеры 1440×810, просмотрены покупка/продажа, экипировка, пауза, новая локация и карта вместе с прежними экранами. Каталог сохранений изолирован. Проверено автоматическое прокручивание к клавиатурному фокусу. Рендер — Xvfb/OpenGL llvmpipe.

Не проверены: запуск приложения на Mac, Retina, физический геймпад, производительность Apple Silicon, длительные сессии и результат GitHub Actions. Предупреждение llvmpipe об отсутствии V-Sync не является замером целевых FPS. macOS-сборка неподписанная, без нотариализации.
