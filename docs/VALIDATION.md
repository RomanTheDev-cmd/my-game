## Новые проверки

- Чистые правила новой линии и трёх отношений: допустимые состояния/фазы, альтернативы, отсутствие повторных наград и изменение границ доверия. Обход графа даёт 36 технических вариантов порядка/подготовки/решения без тупиков; это не 36 сюжетных концовок.
- Миграция v5→v6 и настоящий диск: прежние часы/seed/позиции NPC/активная встреча/память/предметы/навыки/раны сохраняются, новый формат проходит запись/чтение. Отвергаются некорректные группы и стадии, в том числе новая линия до завершения первого задания. Прежние миграции v1–v4 остаются в общем прогоне.
- Четвёртая локация: реальные коллизии/навигация, подход к точкам и дневным/ночным позициям NPC, безопасный переход в обе стороны без бесплатного лечения. Есть постоянный обход; после решения дополнительный проход открывается и в физике, и в навигации, в том числе после загрузки.
- Прохождение через игровые кнопки: принятие, исследование, разговоры, подготовка, решение, возврат и сдача. Проверены все девять сочетаний способов подготовки/решения, бедность/мирный путь и реальные победы над врагами для боевой альтернативы. Расходы/ресурсы/отношения/проход не меняются при ошибке записи; награда не дублируется. При переполненном кошельке UI объясняет требуемое место.
- Доверие: закрытый/открытый ассортимент, покупка настоящего предмета, двуручный слот, реальная дальность/урон, групповые цены, удалённый запрет и отказ записи. Услуга у NPC проверяет доверие, расстояние, ресурсы, запись и фактический результат. Через Viewport.push_input проверены настоящие стрелки/Enter и фокус новых диалогов, без прямого вызова pressed для этих действий.
- 21 проверка совместной экономики при разных уровнях доверия: покупка трав → услуга приготовления → продажа результата/остатков не создаёт монеты. Регрессия воспроизвела прибыль при расходе одной травы; оставлен расход двух. Обычный переносной рецепт по-прежнему требует три.

До реализации воспроизведены отказы новых миграций и связи прогресса. Отдельными RED-проверками подтверждались экономический цикл и отсутствие объяснения переполнения кошелька. Нативное удержание декодера при быстром завершении воспроизводилось в интеграции; Sound.shutdown теперь ждёт отпускания ресурсов после очереди микшера вместо фиксированной паузы. Полный финальный прогон и захваты завершились без ресурсных ошибок. Это не гарантия для всех аудиодрайверов.

Внутренний сценарный граф: 26 узлов/557 достижимых состояний, структурный аудит проходит; 6 Python проверяют сам валидатор повреждёнными графами. Кампания целиком не встроена. Независимое ревью кода существенных подтверждённых дефектов не выявило; оно не подменяет аппаратные испытания.

## Импорт, рендер и сборки

- `bash tools/import.sh`: обычный импорт и чистый импорт отдельной копии без .godot прошли с кодом 0, без ошибок. Старые экраны, ночь/погода, настройки и заклинания также захватываются. Нет обрезания текста/кнопок в просмотренных новых экранах. ## Ограничения

Не проверены запуск приложения на Mac, Retina, физический геймпад, прослушивание/калибровка звука, FPS Apple Silicon и длительные сессии. macOS-сборка неподписанная, без нотариализации. Результат GitHub Actions недоступен через текущий API; локальные сборки не являются результатом CI. Полнота кампании, продолжительность и доля готовности всей RPG не подтверждены.
