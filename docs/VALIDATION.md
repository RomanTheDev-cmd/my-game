# Проверки версии 0.3.0

Дата: 6 ноября 2026, облачная Linux x86_64, Godot 4.6.3 standard.

`godot --headless --editor --import`: выполнено. Ошибок импорта/компиляции в итоговом логе нет.

`bash tools/test.sh`: 225 проверок Godot по 12 наборам, 0 отказов. Боевые действия, меню, переходы и альтернативы проверяются на реальных сценах/CharacterBody2D, сохранения — через отдельный каталог пользователя. Отрицательные прогоны до реализации подтвердили застревание врага и отсутствие боевого заклинания. Физический тест маршрута дополнительно проверяет каждый участок пути, стену и границы.

`python3 tools/audit_story.py`: проверена авторская модель сценария — 26 узлов и 557 достижимых состояний. Это сценарный каркас, не реализованное прохождение кампании. Проверяются явное согласие на смену природы, человеческое продолжение, достижимость обязательных узлов, обязательные состояния NPC и отсутствие достижимых тупиков. `python3 -m unittest discover -s tests -p 'test_*.py'`: 6 проверок валидатора с намеренно повреждёнными вариантами графа, все проходят. Вывод не содержит сюжетного текста.

`godot --headless --export-debug macOS build/Airvel-macOS.zip`: выполнено. `tools/verify_macos.py`: целостность ZIP, пакет и обе архитектуры arm64/x86_64 подтверждены.

`godot --headless --export-debug Linux build/Airvel-Linux.x86_64`: выполнено. Экспортированная игра запускается headless без ошибок.

`tools/verify_pack.py` для обоих пакетов: перевод и лицензия шрифта присутствуют. Внутренний сценарий, документы, тесты, инструменты и рабочие изображения не включены.

`tests/capture.gd`: просмотрены реальные изображения 1440×810 меню, обеих локаций, диалога, настроек, карты, навыков и дневника. Использован Xvfb/OpenGL llvmpipe. Исправлено перекрытие уведомления с описаниями и кнопками.

Не проверены: исполнение приложения на настоящем Mac, Retina, физический геймпад, производительность на Apple Silicon, длинные игровые сессии и реальный результат GitHub Actions. Предупреждение об отсутствии V-Sync у llvmpipe не трактуется как проверка целевых FPS. macOS-сборка неподписанная, без нотариализации.
