# Проверки версии 0.5.0

6 ноября 2026, облачная Linux x86_64, Godot 4.6.3 standard.

`bash tools/test.sh`: **367 проверок Godot, 0 отказов**, 20 наборов. Бой 6; сохранения 36; регионы 9; задания 22; игровой цикл 41; переходы 21; навигация 20; магия 12; предметы/магия 16; настройки 7; развитие 14; альтернативы задания 27; экипировка/торговля 15; торговля в сцене 16; типы врагов 7; исследование/награды 20; миграция экипировки 10; время/миграция v4 и незавершённые встречи 9; правила живого мира 35; интеграция живого мира 24.

Проверки v0.4, сохранённые в полном прогоне, используют настоящие CharacterBody2D, стрелы, стены, блок, кнопки покупки/продажи/экипировки и дисковую запись. Проверены характеристики оружия, совместная защита доспеха/щита, отдельное владение, запрет продажи надетого/сюжетного, невозможность прибыли перепродажей и удалённой торговли. При заблокированной записи покупка и находка не изменяют прежнее состояние.

Проверены третья локация, достижимость привала и наград по маршруту, возвращение/повторный визит/загрузка, охрана и однократность награды. Миграция v3 сохраняет обучение/ранения/предметы, добавляет прежнее неявное снаряжение и не выдаёт ретроактивную награду повторно при загрузке v4. При летящей вражеской стреле сохранение не считается безопасным.

RED v0.4 до реализации: покупка не передавала предмет и не списывала цену (две проверки). Отдельно воспроизведена обрезка уведомления после перестройки UI (две проверки вычисленного положения); исправлены anchor offsets, регрессии включены в полный прогон.

v0.5: часы проходят полночь, ожидание достигает утра, погода определяется сохранёнными временем/seed. Проверены ограничения контекста встреч, отсутствие повторов, стоимость/пределы ресурсов и доверия, отказ для некорректного состояния мира. Интеграция использует фактические CharacterBody2D и кнопки интерфейса: NPC проходит маршрут, часы замирают в меню, ночная торговля запрещена и в backend, важные разговоры доступны. Позиция NPC в пути, погода, незавершённая встреча, память и доверие восстанавливаются из диска. Скидка проверена по фактически списанным монетам.

Заблокированная запись отдыха не лечит и не меняет время; заблокированная запись решения не расходует ресурс и не закрывает встречу. Миграция v4 сохраняет прогресс, деньги, навыки, экипировку и ранения, не начисляет старые награды повторно. RED до добавления v5: запись часов отклонялась и загрузка их теряла (две проверки).

`python3 tools/audit_story.py`: внутренняя сценарная модель 26 узлов/557 достижимых состояний, без сюжетных тупиков по её условиям. Это не интегрированная кампания. `python3 -m unittest discover -s tests -p 'test_*.py'`: 6 проверок валидатора с повреждёнными графами, все проходят. Вывод не содержит сюжетной прозы.

`bash tools/import.sh`: реальный импорт пройден без ошибок. Отдельная проба с сообщением ошибки и кодом 0 отклоняется с кодом 1; CI использует этот wrapper. Коды самого Godot сохраняются через pipefail.

`godot --headless --export-debug macOS build/Airvel-macOS.zip`: выполнено. `tools/verify_macos.py` подтверждает целостность ZIP, пакет и arm64/x86_64.

`godot --headless --export-debug Linux build/Airvel-Linux.x86_64`: выполнено; экспортированная игра запускается headless без ошибок.

`tools/verify_pack.py` для обеих платформ: 99 записей в каждом PCK, перевод и лицензия шрифта присутствуют. Сценарные материалы, документы, тесты, инструменты и build не включены.

`DISPLAY=:99 bash tools/capture.sh`: реальные рендеры 1440×810, просмотрены покупка/продажа, экипировка, пауза, новая локация и карта вместе с прежними экранами; дополнительно ночь, дождь, шейдерный туман и ожидание у костра. Ошибок шейдера/рендера нет. Каталог сохранений изолирован. Проверено автоматическое прокручивание к клавиатурному фокусу. Рендер — Xvfb/OpenGL llvmpipe.
