# Пример передачи работы другому агенту

Это обновляемый пример агента для версии 0.24, не исходный запрос и не неизменная инструкция. Пользователь попросил давать такой промпт в конце выполненной задачи. Точный коммит проверить через git log -1 и git ls-remote; не откатывать более новую работу ради этой заметки. Версия 0.24 развита поверх cf06c38376741a245c20e49e8e4d3b5b383ab5a8 (0.23).

```text
Продолжай разработку RPG «Эйрвель» по исходному ТЗ в приватном RomanTheDev-cmd/my-game, ветка feature/first-playable. Последняя проверенная версия 0.24; сначала сверь status/HEAD/remote и сохрани незавершённое. Если ветка уже продвинулась дальше, не откатывай её и не начинай проект заново.

Прочитай AGENTS.md, CONTINUE_HERE.md, PROJECT_STATE.md, ROADMAP.md, docs/VALIDATION.md, docs/INITIAL_REQUEST.md, docs/INITIAL_PROMPT.ru.txt, docs/USER_CONTEXT.ru.md и docs/SPECIFICATION.ru.md. Агентские планы — проверяемые рекомендации, не неизменная истина. Оригинал запроса не меняй, дополнения храни отдельно.

Среда может быть новой: если нет /workspace, клонируй ветку, выполни bash tools/bootstrap.sh (Godot 4.6.3 standard и шаблоны с проверкой SHA-512) и добавь ~/.cache/airvel-toolchain/bin в PATH; затем воспроизведи базовый прогон. Проверки 0.24: 3350 Godot/92 набора + 6 Python; чистый импорт, рендеры, macOS universal/Linux и запуск Linux прошли. Эти результаты относятся к указанной версии, новые изменения проверяй заново по рискам.

В 0.24 встроены три процедурные глубины под старой караульней (зерно прохождения, гарантированная проходимость, проверка сохранений по восстановленной раскладке); в 0.23 — необязательное дело-подземелье с новым противником и вторым боссом; участки 0.16–0.22 тоже реализованы. Не повторяй их. Предлагаемый следующий блок — развитие случайных событий из ТЗ §12: встречи с продолжением по региону/погоде/времени/репутации/природе/решениям, с сохраняемыми последствиями и без повторов. Детали и масштаб выбери после проверки кода/ТЗ/новых указаний.

Цель — полноценная RPG. Сохрани человеческое начало, добровольность природы, полезный обычный путь и доступ после возвращения. Диалоги/ответы различаются по природе/облику/возвращению/прошлым поступкам с памятью. Пользователь — будущий игрок: не раскрывай сюжет, загадки и концовки. Управление клавиатурой/мышью, геймпада нет. Делай содержательные задачи подряд без постоянного «продолжать?», сохраняя качество.

Проверь старые saves/миграции, место каждого события в правилах и реальные ввод/физику/движение/ошибки записи/загрузку. Для значимого изменения — независимое ревью; затем общий прогон/импорт/рендеры/сборки. Обновляй этап, проверенное/непроверенное, рекомендации и пример продолжения.

Push в существующую приватную feature/first-playable разрешён. Main не сливать, не force-push, приватность и облачную публикацию не менять. После отправки сверь удалённый SHA и чистоту. В конце задачи дай готовый промпт передачи с актуальным коммитом; не обещай фоновую работу после ответа. Реальный Mac, аппаратный звук и Apple Silicon FPS пока не проверены.
```
