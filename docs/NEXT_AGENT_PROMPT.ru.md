# Пример передачи работы другому агенту

Это обновляемый пример агента для версии0.22, не исходный запрос и не неизменная инструкция. Пользователь попросил давать такой промпт в конце выполненной задачи. Точный коммит проверить через git log -1 и git ls-remote; не откатывать более новую работу ради этой заметки. Версия0.22 развита поверх19e7de354f1d47cfc036039a39fb3bcf3f8628c9.

```text
Продолжай разработку «Эйрвель» по исходному ТЗ в приватном RomanTheDev-cmd/my-game, ветка feature/first-playable. Последняя проверенная версия0.22; сначала сверь status/HEAD/remote и сохрани незавершённое. Если ветка уже продвинулась дальше, не откатывай её и не начинай проект заново.

Прочитай AGENTS.md, CONTINUE_HERE.md, PROJECT_STATE.md, ROADMAP.md, docs/VALIDATION.md, docs/INITIAL_REQUEST.md, docs/INITIAL_PROMPT.ru.txt, docs/USER_CONTEXT.ru.md и docs/SPECIFICATION.ru.md. Агентские планы — проверяемые рекомендации, не неизменная истина. Оригинал промпта не меняй, дополнения храни отдельно.

Проверки0.22:2843 Godot/84 набора +6 Python; импорт/рендеры/macOS universal/Linux и запуск Linux прошли. Godot4.6.3 standard/GDScript; в подготовленной среде source /workspace/.godot-env/env.sh. Эти результаты относятся к указанной версии, новые изменения проверяй заново по рискам.

В0.22 уже встроен первый общий итог с различающимися сохраняемыми последствиями в трёх регионах и продолжением исследования; до него основные участки0.16–0.21. Не повторяй их. Предлагаемый следующий блок — содержательное необязательное исследовательское/боевое дело с отличающимся противником/боссом, учитывающее выбранные последствия и историю героя. Детали и масштаб выбери после проверки кода/ТЗ/новых указаний.

Цель — полноценная RPG. Сохрани человеческое начало, добровольность природы, полезный обычный путь и доступ после возвращения. Диалоги/ответы различаются по природе/облику/возвращению/прошлым поступкам с памятью. Пользователь — будущий игрок: не раскрывай сюжет, загадки и концовки. Управление клавиатурой/мышью, геймпада нет. Делай содержательные задачи подряд без постоянного «продолжать?», сохраняя качество.

Проверь старые saves/миграции и реальные ввод/физику/движение/ошибки записи/загрузку/численные границы. Для значимого изменения — независимое ревью; затем соответствующие общий прогон/импорт/рендеры/сборки. Обновляй этап, проверенное/непроверенное, рекомендации и пример продолжения.

Push в существующую приватную feature/first-playable разрешён. Main не сливать, не force-push, приватность и облачную публикацию не менять. После отправки сверь удалённый SHA и чистоту. В конце задачи дай готовый промпт передачи с актуальным коммитом; не обещай фоновую работу после ответа. Реальный Mac, аппаратный звук и Apple Silicon FPS пока не проверены.
```
