# План 0.8: первая встреча с боссом

Продолжение авторизовано пользователем без остановок/согласования мелких шагов. Ветка feature/first-playable. Сюжет только в локализации/data/narrative. Блок 0.7 закрыт (7db3919).

1. Правила боя (scripts/combat/boss_rules.gd, tests/test_boss_rules.gd): фазы, три читаемые атаки, проверка попаданий, окна восстановления. Проверка: независимые геометрические примеры/границы, исходный RED на поведении.
2. Состояние задания (scripts/quests/trial_rules.gd, Session, SaveStore, tests/test_trial.gd): хранить через существующие массивы флагов v6 без сброса старого мира, валидировать порядок. Победа и награда атомарны, ошибка записи позволяет повтор. Проверка настоящим диском/восстановлением и отказом записи.
3. Связанная локация (каталог, waterworks_landscape, World, tests/test_waterworks.gd): постоянный выход, привал, две точки исследования, арена с препятствиями. Проверка навигации и переходов с сохранёнными показателями.
4. Актёр босса (boss_enemy, World, tests/test_boss_combat.gd): фазы/телеграфы/конус/рывок/радиальный удар, стены, блок/перекат, три сложности, сброс при отступлении, ожидание записи при победе. Проверка реальной физикой и Player.
5. Игровая линия/UI (trial_screen, main, commission_screen, CSV, tests/test_trial_gameplay.gd): принять, исследовать, начать, победить, вернуться/сдать; HUD босса, дневник и клавиатура. Проверка настоящих кнопок/ввода/переходов/загрузки/повтора.
6. Контроль: полный прогон, обычный/чистый импорт, реальные рендеры и обе сборки/пакеты. Ревью. Обновление состояния/инструкций/промпта, commit/push без merge.

Зависимости: 1→4, 2→3/5, 3→4/5, все→6. После 1/2 — фокусные тесты; после 3–5 — реальный игровой цикл; затем полный прогон.
Риски: повтор награды, тупик после ошибки диска, непроходимые точки/рывки через стены, невидимая атака. Снижение: последовательные флаги, write-before-apply, доступный выход, реальная навигация/физика и просмотр телеграфов. Босс не персонаж-друг; нет обязательной смерти близких. Полная кампания и баланс/часы/FPS этим блоком не объявляются готовыми.
