Два знакомых региональных участника дают собственное подтверждаемое согласие; перемещение видно в одной активной локации, личная память не меняется. 2. В ротонде — изменяемое распределение двух участников, реальные движение/Nav и удержание постов. Две физические опоры с видимыми положениями; нужная настройка объясняется прежними решениями, без угадывания. Путь героя проверяется настоящим движением между последовательными точками при присутствующих участниках. Это подготовка, не закадровое спасение.

Ошибка финальной записи имеет явный повтор без наград/ресурсов. v9 без новых обязательных полей, строгая согласованность/namespace.
4. Проверки правил, реального управления/движения NPC/героя, истории/обликов/возвращения, отказов диска/загрузки/старых saves; независимое read-only ревью по requesting-code-review.
