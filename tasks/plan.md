# Рабочий ориентир 0.24

BASE cf06c38376741a245c20e49e8e4d3b5b383ab5a8. План агента — рекомендация, не неизменная истина.

1. Первая гибридная генерация по ТЗ: необязательные глубины под старой караульней; раскладка из зерна прохождения (необязательный ключ world_state, старые v9 используют зерно мира).
2. Чистый детерминированный генератор: сетка комнат, связующее дерево от входа (гарантия проходимости), петли (одна — завал для летучей мыши), дальний замковый зал не у входа, спокойные комнаты у входа, роли комнат, враги по глубине и элитный страж.
3. Валидация сохранений: каждый ID врага/травы/тайника сверяется с восстановленной раскладкой; доступ глубин по замковым камням; уникальная броня только после третьего камня.
4. Мир: ландшафт по раскладке, лестница/записка, вход из караульни, выход наверх, карта, журнал; различия путей — выслеживание тайников, перелёт завала, свет против отзвуков, туман.
5. Свойственные тесты по многим зёрнам, настоящие сцены и ввод, отказ записи, загрузка, смерть; независимое ревью, полный прогон, рендеры, сборки, документы и промпт передачи.
