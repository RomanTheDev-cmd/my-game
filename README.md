# Эйрвель

Одиночная 2D Action RPG на Godot 4.6.3 и GDScript. Основной язык — русский, целевая платформа — macOS (Apple Silicon). Игра работает локально без сетевых сервисов.

**Статус: первый игровой этап, не готовая RPG.** Сейчас доступны одна локация, один короткий проверочный квест, три противника, ближний бой, защита, перекат, исцеление, сбор предметов, дневник, три режима сложности и сохранения. Цель 30–50 часов ещё не достигнута. Текущее название рабочее; проверка товарных знаков не выполнена.

## Запуск

Откройте `project.godot` в Godot **4.6.3 standard** (не .NET) и нажмите F6/F5 для сцены/проекта. Либо из каталога проекта:

```sh
godot --editor --path .
```

На подготовленной облачной машине перед командами Godot выполните:

```sh
source /workspace/.godot-env/env.sh
cd /workspace/my-game
godot --headless --editor --import
bash tools/test.sh
```

На чистом Linux `bash tools/bootstrap.sh` загружает движок и шаблоны с официального GitHub, проверяет закреплённые SHA-512 и устанавливает их в пользовательские каталоги. Если движка нет в PATH, после скрипта добавьте `${XDG_CACHE_HOME:-$HOME/.cache}/airvel-toolchain/bin` в PATH. Python 3, curl, unzip, sha512sum и ripgrep требуются для инструментов разработки. Pillow требуется только для необязательной перегенерации авторских спрайтов.

## Управление

| Действие | Клавиатура / мышь | Геймпад (раскладка Xbox) |
|---|---|---|
| Движение | WASD / стрелки | Левый стик |
| Удар | ЛКМ (по курсору) / J (по направлению движения) | X |
| Блок | ПКМ / K | LB |
| Перекат | Пробел | A |
| Исцеление | Q | Y |
| Взаимодействие | E | B |
| Пауза | Esc | Start |
| Дневник / сумка | Tab | Back |
| Сохранить / загрузить | F5 / F9 | Через меню паузы |
| Полный экран | F11 | Через настройки |

Сохранение разрешено вдали от противников. У костра герой восстанавливается. Гибель возвращает к последнему сохранённому привалу с восстановлением состояния мира. Начальный герой — человек; меню выбора вампира/оборотня отсутствует.

Сохранения находятся в `user://save.json`, предыдущая исправная версия — `save.json.bak`. На macOS стандартный каталог Godot: `~/Library/Application Support/Godot/app_userdata/Эйрвель/`. Автотесты используют отдельный временный каталог и не затрагивают сохранения игрока.

## Сборки

```sh
mkdir -p build
godot --headless --export-debug macOS build/Airvel-macOS.zip
python3 tools/verify_macos.py build/Airvel-macOS.zip
python3 tools/verify_pack.py build/Airvel-macOS.zip
godot --headless --export-debug Linux build/Airvel-Linux.x86_64
```

macOS-архив содержит универсальное `.app` для arm64 и x86_64. Это неподписанная тестовая сборка, без нотариализации Apple. Запуск на целевом Mac, Retina, физический геймпад и производительность 60 FPS требуют отдельных испытаний. В облаке проверяются экспорт и структура бинарника, а не исполнение macOS-приложения.

GitHub Actions (`Check and build Godot`) импортирует ресурсы, запускает тесты и создаёт артефакт `Airvel-macOS-development`. После успешного запуска workflow скачайте ZIP из раздела **Actions → запуск → Artifacts**. До отправки проекта и первого запуска CI это лишь настроенный процесс, не подтверждённый GitHub результат.

## Структура

- `scripts/actors` — герой и поведение противников.
- `scripts/combat` — правила расчёта урона.
- `scripts/systems` — ввод, сессия, проверка и запись сохранений.
- `scripts/world` — локация, коллизии, взаимодействия.
- `scripts/ui` — меню и HUD.
- `data/localization/strings.csv` — стабильные ключи и русские тексты; перевод импортируется встроенной системой Godot.
- `data/narrative` — внутренние материалы, **содержат спойлеры**, в сборку не включаются.
- `tests` — проверки правил, сохранений и реального игрового цикла.

Полное исходное ТЗ: `docs/SPECIFICATION.ru.md`. Следующие этапы и ограничения: `ROADMAP.md`, `PROJECT_STATE.md`. Исходные спрайты созданы для проекта; код генератора — `tools/generate_art.py`. Шрифты DejaVu распространяются по лицензии в `assets/fonts/LICENSE.txt`.
