# Эйрвель

Одиночная 2D Action RPG на Godot 4.6.3 и GDScript. Основной язык — русский, целевая платформа — macOS (Apple Silicon). Игра работает локально без сетевых сервисов.

**Статус: версия 0.22.0, ранняя разработка, не готовая RPG.** Сейчас доступны двенадцать связанных локаций, два небольших задания, многоэтапная линия с альтернативами и отдельное задание с исследованием/боссом, девятнадцать обычных противников трёх типов и первый босс, ближний бой, защита, перекат, исцеление, боевой световой заряд, замедление и защитный покров, приготовление и применение настоев, опыт и навыки, карта, снаряжение, торговля, одноразовые находки, сбор предметов, дневник, три режима сложности и сохранения. Добавлены смена суток, освещение, дождь/туман, базовые расписания NPC и четыре контекстные мирные встречи с памятью решений. Цель 30–50 часов ещё не достигнута. Текущее название рабочее; проверка товарных знаков не выполнена.

В 0.22 добавлен первый игровой вариант общего итога: собственная позиция героя, разные разговоры с прежними участниками и три отдельно подтверждаемых решения с настоящими последствиями в знакомых регионах. Выбранный вариант добавляет действующие привалы, открывает физические проходы либо даёт однократные общие запасы. Прежняя история сохраняется, после итога можно продолжать исследование. Это развитие ранней связной линии; полный объём кампании, глубина ветвей и целевые часы ещё не готовы.

Обычная работа, действительные снаряды и особые подходы имеют собственные условия и цены. Настройки двух физических опор зависят от прежних решений и объяснены в интерфейсе. ## Запуск

Откройте `project.godot` в Godot **4.6.3 standard** (не .NET) и нажмите F6/F5 для сцены/проекта. Либо из каталога проекта:

```sh
godot --editor --path .
```

На подготовленной облачной машине перед командами Godot выполните:

```sh
source /workspace/.godot-env/env.sh
cd /workspace/my-game
bash tools/import.sh
bash tools/test.sh
```

На чистом Linux `bash tools/bootstrap.sh` загружает движок и шаблоны с официального GitHub, проверяет закреплённые SHA-512 и устанавливает их в пользовательские каталоги. Если движка нет в PATH, после скрипта добавьте `${XDG_CACHE_HOME:-$HOME/.cache}/airvel-toolchain/bin` в PATH. Python 3, curl, unzip, sha512sum и ripgrep требуются для инструментов разработки. Pillow требуется только для необязательной перегенерации авторских спрайтов. `DISPLAY=:99 bash tools/capture.sh` снимает интерфейсы на готовом X-сервере с отдельным временным каталогом сохранений.

## Управление

| Действие | Клавиатура / мышь | Геймпад (раскладка Xbox) |
|---|---|---|
| Движение | WASD / стрелки | Левый стик |
| Удар | ЛКМ (по курсору) / J (по направлению движения) | X |
| Блок | ПКМ / K | LB |
| Перекат | Пробел | A |
| Исцеление | Q | Y |
| Световой заряд | F (в сторону курсора или движения) | RB |
| Холод / защитный покров | G / R | Через книгу заклинаний |
| Книга заклинаний | B | Через меню паузы |
| Природа / способность / облик | N / V / U / Y | Через меню паузы |
| Лечебный настой | H | Через сумку |
| Карта | M | Через меню паузы |
| Навыки | C | Через меню паузы |
| Снаряжение | I | Через меню паузы |
| Взаимодействие | E | B |
| Ожидание у костра | T | Через меню паузы |
| Пауза | Esc | Start |
| Дневник / сумка | Tab | Back |
| Сохранить / загрузить | F5 / F9 | Через меню паузы |
| Полный экран | F11 | Через настройки |

Двенадцать авторских локаций соединены указателями. Взаимодействие через E показывает доступный переход. Переход автоматически сохраняет местоположение и состояние мира, сохраняя текущее здоровье и магию.

Снаряжение открывается на I. Оружие меняет урон, дальность и темп атаки, доспех снижает входящий урон, щит усиливает блок. Двуручное оружие занимает обе руки. Вещи остаются в собственности после снятия; надетое снаряжение нельзя продать. У торговца через E доступны покупка и продажа.

Награды встреч и одноразовые находки сохраняются. Если запись на диск не удалась, сделка или открытие сундука не меняют прежние деньги и предметы. Во время полёта вражеского снаряда сохранение не считается безопасным.

Три травы превращаются в настой через дневник (Tab); настой восстанавливает 60 здоровья. За встречи и задания начисляется опыт. На экране навыков (C) можно усилить оружие, световой заряд, защиту, исцеление, холод и покров. Три новые специализации имеют по два ранга за существующие очки; увеличение силы меняет и расход магии. Учиться можно в безопасности и обычном облике. Несовместимые с природой чары нельзя изучать; прежние ранги сохраняются и снова работают после возвращения. Обучение сначала записывается на диск. Уровни требуют всё больше опыта, очки и зависимости навыков проверяются при загрузке.

Сохранение разрешено вдали от противников. Перед безопасным сближением с противником автоматически записывается контрольная точка. У костра E восстанавливает героя и пропускает полчаса. T открывает ожидание на час или до следующего утра. Отдых возможен только в безопасности; при ошибке сохранения время и показатели остаются прежними. Гибель возвращает к последнему сохранённому привалу с восстановлением состояния мира. Начальный герой — человек; меню выбора вампира/оборотня отсутствует.

Сохранения находятся в `user://save.json`, предыдущая исправная версия — `save.json.bak`. На macOS стандартный каталог Godot: `~/Library/Application Support/Godot/app_userdata/Эйрвель/`. Формат сохранения — v9; файлы v1/v2/v3/v4/v5/v6/v7/v8 автоматически переносятся без сброса задания, предметов и состояния мира. Опыт и новая экономическая награда за прежние встречи учитываются при переносе. Прежнее неявное снаряжение становится явным стартовым комплектом. Настройки оконного режима и сложности сохраняются отдельно в user://preferences.json; повреждённые настройки возвращаются к безопасным значениям по умолчанию. Автотесты используют отдельный временный каталог и не затрагивают сохранения игрока.

В игровом мире одна реальная секунда соответствует одной игровой минуте; меню останавливают время. День, ночь и погода меняются по сохранённому времени, загрузка не перебрасывает погоду. Внутри помещений нет осадков. Торговля доступна с 07:00 до 21:00; NPC перемещаются по расписанию, их текущие позиции видны на карте и сохраняются. Важные разговоры доступны и ночью.

Контекстные встречи зависят от локации, времени, погоды и отношений. Решения запоминаются; расход ресурсов и последствия записываются вместе. Дневник показывает отношения трёх групп. Доверие влияет на цены, доступ к отдельному снаряжению и помощь с приготовлением настоев; услуга у соответствующего NPC требует две травы вместо трёх. Новая связная линия учитывает решения и меняет доступный проход в мире. Добавлен первый эпизод сообществ: добровольное подтверждённое вступление по текущему пути, разные способы помощи, сохраняемый итоговый выбор и полезное снаряжение. После возвращения к человеческой природе прежнее членство и дело сохраняются; общий человеческий способ остаётся доступен. Это начальная система отношений и первое дело сообществ; полноценные фракции ещё предстоят.

B открывает книгу четырёх заклинаний с описаниями, расходом магии и кнопками применения. Без изученных улучшений G выпускает снаряд холода: 12 урона и замедление движения на 45% на 4 секунды. R создаёт покров: 30 поглощаемого урона на 6 секунд, восстановление применения — 10 секунд. Защитный навык усиливает покров. Изученные ранги меняют фактические лечение, силу и длительность холода, прочность/длительность/восстановление покрова; книга показывает действующие эффекты и цены. Уже выпущенный снаряд сохраняет прежние параметры при дальнейшем обучении. Стены останавливают снаряды, замедление не складывается в полную остановку. Временные боевые эффекты пока не переносятся между локациями или загрузками. Добавлено отдельное добровольное дело с применением холода, исцеления и покрова к реальным местам через E. Изученные ранги меняют воздействие; обычная работа доступна каждому пути. Результаты сохраняются и меняют проход, доступ к запасу и действующему месту отдыха. Цена, ограничения природы и готовность показываются в диалоге и дневнике. При отказе записи ресурс и результат сохраняют прежнее состояние.

В настройках доступны общая громкость, эффекты и окружение. Нулевое значение выключает соответствующий канал. Шаги, бой, магия и взаимодействия имеют звуковую обратную связь; ветер, дождь, помещение и костёр — отдельное окружение. Это первоначальная библиотека из 16 авторских синтезированных WAV, не готовый саундтрек. Генератор — `tools/generate_audio.py`, проверка PCM — `tools/verify_audio.py`. Прослушивание и калибровка на целевых динамиках/наушниках Mac ещё нужны.

В дополнительной исследовательской ветке есть первый босс с двумя фазами, тремя предупреждаемыми атаками и окнами восстановления. Стены останавливают рывок и закрывают героя от ударов; блок, перекат и холод используют общие правила. Можно отступить и повторить попытку. Победа записывается до исчезновения противника; при ошибке записи доступна повторная фиксация через E.

Игрок по-прежнему начинает человеком. В ходе игры доступно добровольное предложение с объяснением последствий и отдельным подтверждением: человеческий защитный обет либо первый кровный путь. N — описание природы и доступных действий, V — способность, U — временный боевой облик. Начальная вампирская система включает запас крови, ночную регенерацию, солнечную слабость, магию крови и боевую форму с затратами/ограничениями. Добавлено постепенное обучение исследовательским формам: Z — летучая мышь над низкими препятствиями, X — туман через узкие щели. Они расходуют кровь и не атакуют; обычные стены остаются непроходимыми. U возвращает обычный облик в безопасную точку. Два необязательных испытания открывают обычный выход после находки; при истощении до находки герой возвращается наружу. Дневник объясняет обучение и применение. Все четырнадцать NPC отдельно реагируют на оба облика. Туман труднее заметить издалека; близкий враг его видит. Уже заметивший цель или получивший урон обычный враг хранит тревогу ещё четыре секунды — её показывает знак над головой. Начатую атаку и преследование босса смена формы не отменяет; отдых около угрозы закрыт.

Возвращение к человечности — отдельная небольшая линия, а не кнопка свободного переключения природы. История и последствия сохраняются. Тринадцать NPC по-разному реагируют на природу, облик и возвращение; ответы и память разговоров влияют на доверие однократно. Важные задания и торговля остаются доступны через продолжение разговора и возврат в человеческий облик.

Добавлена самостоятельная начальная линия ликантропии: новая лесная локация и следопыт, изучение следов/предупреждений, отдельное подтверждение или полезная человеческая альтернатива. U — быстрый волк с чувством следа; Y — гибрид после освоения трёх находок; V — вой. Выдержка расходуется в формах и восстанавливается человеком; луна влияет на силу и регенерацию без принудительного превращения. Находки доступны и обычному человеку вблизи. Возвращение имеет собственные действия/цену и сохраняет память; восемь NPC различают волчий путь и его последствия.

## Сборки

```sh
mkdir -p build
godot --headless --export-debug macOS build/Airvel-macOS.zip
python3 tools/verify_macos.py build/Airvel-macOS.zip
python3 tools/verify_pack.py build/Airvel-macOS.zip
godot --headless --export-debug Linux build/Airvel-Linux.x86_64
```

macOS-архив содержит универсальное `.app` для arm64 и x86_64. Это неподписанная тестовая сборка, без нотариализации Apple. Запуск на целевом Mac, Retina, физический геймпад и производительность 60 FPS требуют отдельных испытаний. В облаке проверяются экспорт и структура бинарника, а не исполнение macOS-приложения.

GitHub Actions (`Check and build Godot`) импортирует ресурсы, запускает тесты и создаёт артефакт `Airvel-macOS-development`. После успешного запуска workflow скачайте ZIP из раздела **Actions → запуск → Artifacts**. Ветки main и feature/first-playable отправлены в приватный GitHub. Результат GitHub Actions ещё не проверен: API недоступен из текущей среды. Проверенные локальные сборки не подменяют результат CI.

## Структура

- `scripts/actors` — герой и поведение противников.
- `scripts/combat` — правила расчёта урона.
- `scripts/magic` — затраты заклинаний и физический снаряд.
- `scripts/items` — рецепты, расход предметов, экипировка, торговля и однократные награды.
- `scripts/nature` — природа, облик, ресурсы, ограничения и память личных разговоров.
- `scripts/progression` — опыт, уровни, очки и зависимости навыков.
- `scripts/quests` — граф событий, условия переходов и однократная выдача награды.
- `scripts/factions` — группы, границы доверия и последствия решений.
- `scripts/systems` — ввод, сессия, проверка и запись сохранений.
- `scripts/world` — локация, коллизии, взаимодействия.
- `scripts/ui` — меню и HUD.
- `data/localization/strings.csv` — стабильные ключи и русские тексты; перевод импортируется встроенной системой Godot.
- `data/narrative` — внутренние материалы, **содержат спойлеры**, в сборку не включаются.
- `tests` — проверки правил, сохранений и реального игрового цикла.

Полное исходное ТЗ: `docs/SPECIFICATION.ru.md`. Следующие этапы и ограничения: `ROADMAP.md`, `PROJECT_STATE.md`. Исходные спрайты созданы для проекта; код генератора — `tools/generate_art.py`. Шрифты DejaVu распространяются по лицензии в `assets/fonts/LICENSE.txt`.
