# Эйрвель

Одиночная 2D Action RPG на Godot 4.6.3 и GDScript. Основной язык — русский, целевая платформа — macOS (Apple Silicon). Игра работает локально без сетевых сервисов.

**Статус: версия 0.6.0, ранняя разработка, не готовая RPG.** Сейчас доступны три связанные локации, два небольших задания, включая ветку с альтернативными решениями, восемь противников трёх типов, ближний бой, защита, перекат, исцеление, боевой световой заряд, замедление и защитный покров, приготовление и применение настоев, опыт и навыки, карта, снаряжение, торговля, одноразовые находки, сбор предметов, дневник, три режима сложности и сохранения. Добавлены смена суток, освещение, дождь/туман, базовые расписания NPC и четыре контекстные мирные встречи с памятью решений. Цель 30–50 часов ещё не достигнута. Текущее название рабочее; проверка товарных знаков не выполнена.

Инструкции и готовый промпт для продолжения разработки: [CONTINUE_HERE.md](CONTINUE_HERE.md).

## Запуск

Откройте `project.godot` в Godot **4.6.3 standard** (не .NET) и нажмите F6/F5 для сцены/проекта. Либо из каталога проекта:

```sh
godot --editor --path .
```

На подготовленной облачной машине перед командами Godot выполните:

```sh
source /workspace/.godot-env/env.sh
cd /workspace/my-game
bash tools/import.sh
bash tools/test.sh
```

На чистом Linux `bash tools/bootstrap.sh` загружает движок и шаблоны с официального GitHub, проверяет закреплённые SHA-512 и устанавливает их в пользовательские каталоги. Если движка нет в PATH, после скрипта добавьте `${XDG_CACHE_HOME:-$HOME/.cache}/airvel-toolchain/bin` в PATH. Python 3, curl, unzip, sha512sum и ripgrep требуются для инструментов разработки. Pillow требуется только для необязательной перегенерации авторских спрайтов. `DISPLAY=:99 bash tools/capture.sh` снимает интерфейсы на готовом X-сервере с отдельным временным каталогом сохранений.

## Управление

| Действие | Клавиатура / мышь | Геймпад (раскладка Xbox) |
|---|---|---|
| Движение | WASD / стрелки | Левый стик |
| Удар | ЛКМ (по курсору) / J (по направлению движения) | X |
| Блок | ПКМ / K | LB |
| Перекат | Пробел | A |
| Исцеление | Q | Y |
| Световой заряд | F (в сторону курсора или движения) | RB |
| Холод / защитный покров | G / R | Через книгу заклинаний |
| Книга заклинаний | B | Через меню паузы |
| Лечебный настой | H | Через сумку |
| Карта | M | Через меню паузы |
| Навыки | C | Через меню паузы |
| Снаряжение | I | Через меню паузы |
| Взаимодействие | E | B |
| Ожидание у костра | T | Через меню паузы |
| Пауза | Esc | Start |
| Дневник / сумка | Tab | Back |
| Сохранить / загрузить | F5 / F9 | Через меню паузы |
| Полный экран | F11 | Через настройки |

Три авторские локации соединены указателями. Взаимодействие через E показывает доступный переход. Переход автоматически сохраняет местоположение и состояние мира, сохраняя текущее здоровье и магию.

Снаряжение открывается на I. Оружие меняет урон, дальность и темп атаки, доспех снижает входящий урон, щит усиливает блок. Двуручное оружие занимает обе руки. Вещи остаются в собственности после снятия; надетое снаряжение нельзя продать. У торговца через E доступны покупка и продажа.

Награды встреч и одноразовые находки сохраняются. Если запись на диск не удалась, сделка или открытие сундука не меняют прежние деньги и предметы. Во время полёта вражеского снаряда сохранение не считается безопасным.

Три травы превращаются в настой через дневник (Tab); настой восстанавливает 60 здоровья. За встречи и задания начисляется опыт. На экране навыков (C) можно усилить оружие, заряд или защиту. Уровни требуют всё больше опыта, очки и зависимости навыков проверяются при загрузке.

Сохранение разрешено вдали от противников. Перед безопасным сближением с противником автоматически записывается контрольная точка. У костра E восстанавливает героя и пропускает полчаса. T открывает ожидание на час или до следующего утра. Отдых возможен только в безопасности; при ошибке сохранения время и показатели остаются прежними. Гибель возвращает к последнему сохранённому привалу с восстановлением состояния мира. Начальный герой — человек; меню выбора вампира/оборотня отсутствует.

Сохранения находятся в `user://save.json`, предыдущая исправная версия — `save.json.bak`. На macOS стандартный каталог Godot: `~/Library/Application Support/Godot/app_userdata/Эйрвель/`. Формат сохранения — v5; файлы v1/v2/v3/v4 автоматически переносятся без сброса задания, предметов и состояния мира. Опыт и новая экономическая награда за прежние встречи учитываются при переносе. Прежнее неявное снаряжение становится явным стартовым комплектом. Настройки оконного режима и сложности сохраняются отдельно в user://preferences.json; повреждённые настройки возвращаются к безопасным значениям по умолчанию. Автотесты используют отдельный временный каталог и не затрагивают сохранения игрока.

В игровом мире одна реальная секунда соответствует одной игровой минуте; меню останавливают время. День, ночь и погода меняются по сохранённому времени, загрузка не перебрасывает погоду. Внутри помещений нет осадков. Торговля доступна с 07:00 до 21:00; NPC перемещаются по расписанию, их текущие позиции видны на карте и сохраняются. Важные разговоры доступны и ночью.

Контекстные встречи зависят от локации, времени, погоды и отношений. Решения запоминаются; расход ресурсов и последствия записываются вместе. Доверие дорожных жителей видно в дневнике и влияет на цены. Это начальная система отношений, полноценные фракции ещё предстоят.

B открывает книгу четырёх заклинаний с описаниями, расходом магии и кнопками применения. G выпускает снаряд холода: 12 урона и замедление движения на 45% на 4 секунды. R создаёт покров: 30 поглощаемого урона на 6 секунд, восстановление применения — 10 секунд. Защитный навык усиливает покров. Стены останавливают снаряды, замедление не складывается в полную остановку. Временные боевые эффекты пока не переносятся между локациями или загрузками.

В настройках доступны общая громкость, эффекты и окружение. Нулевое значение выключает соответствующий канал. Шаги, бой, магия и взаимодействия имеют звуковую обратную связь; ветер, дождь, помещение и костёр — отдельное окружение. Это первоначальная библиотека из 16 авторских синтезированных WAV, не готовый саундтрек. Генератор — `tools/generate_audio.py`, проверка PCM — `tools/verify_audio.py`. Прослушивание и калибровка на целевых динамиках/наушниках Mac ещё нужны.

## Сборки

```sh
mkdir -p build
godot --headless --export-debug macOS build/Airvel-macOS.zip
python3 tools/verify_macos.py build/Airvel-macOS.zip
python3 tools/verify_pack.py build/Airvel-macOS.zip
godot --headless --export-debug Linux build/Airvel-Linux.x86_64
```

macOS-архив содержит универсальное `.app` для arm64 и x86_64. Это неподписанная тестовая сборка, без нотариализации Apple. Запуск на целевом Mac, Retina, физический геймпад и производительность 60 FPS требуют отдельных испытаний. В облаке проверяются экспорт и структура бинарника, а не исполнение macOS-приложения.

GitHub Actions (`Check and build Godot`) импортирует ресурсы, запускает тесты и создаёт артефакт `Airvel-macOS-development`. После успешного запуска workflow скачайте ZIP из раздела **Actions → запуск → Artifacts**. Ветки main и feature/first-playable отправлены в приватный GitHub. Результат GitHub Actions ещё не проверен: API недоступен из текущей среды. Проверенные локальные сборки не подменяют результат CI.

## Структура

- `scripts/actors` — герой и поведение противников.
- `scripts/combat` — правила расчёта урона.
- `scripts/magic` — затраты заклинаний и физический снаряд.
- `scripts/items` — рецепты, расход предметов, экипировка, торговля и однократные награды.
- `scripts/progression` — опыт, уровни, очки и зависимости навыков.
- `scripts/quests` — граф событий, условия переходов и однократная выдача награды.
- `scripts/systems` — ввод, сессия, проверка и запись сохранений.
- `scripts/world` — локация, коллизии, взаимодействия.
- `scripts/ui` — меню и HUD.
- `data/localization/strings.csv` — стабильные ключи и русские тексты; перевод импортируется встроенной системой Godot.
- `data/narrative` — внутренние материалы, **содержат спойлеры**, в сборку не включаются.
- `tests` — проверки правил, сохранений и реального игрового цикла.

Полное исходное ТЗ: `docs/SPECIFICATION.ru.md`. Следующие этапы и ограничения: `ROADMAP.md`, `PROJECT_STATE.md`. Исходные спрайты созданы для проекта; код генератора — `tools/generate_art.py`. Шрифты DejaVu распространяются по лицензии в `assets/fonts/LICENSE.txt`.
