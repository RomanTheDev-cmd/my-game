# Состояние проекта

## Текущий этап

0.1.0 — первая локальная играбельная основа Эйрвеля. **Не полноценная RPG и не релиз.** Исходное ТЗ не заменено этим объёмом: его остальные требования остаются в ROADMAP.md.

Реализовано: проект Godot 4.6.3, отдельные модули героя/противника/мира/ввода/сохранений/интерфейса, ручная первая локация, управление, ближний удар с дугой попадания, предупреждение атаки врага, блок, перекат, исцеление, три сложности, диалог и один проверочный квест, сбор ресурсов и сумка, меню, дневник, контрольная точка и возврат после гибели. Начальная природа только человеческая. Переводы — встроенный CSV-импорт Godot и стабильные ключи.

Сохранение атомарно записывается через временный файл, сохраняет исправный предыдущий слот; повреждённый основной слот восстанавливается из резервного. Проверяются версия/типы/границы/согласованность предмета и стадии проверочного квеста. Побеждённые противники и собранные ресурсы остаются в соответствующем состоянии после загрузки. Автосохранение пока только при принятии/завершении задания; контрольные точки боя и много слотов ещё предстоят.

## Проверки

- Godot headless: правила боя — 6 проверок, сохранения — 22, игровой цикл — 28. Всего 56; последний отдельный прогон прошёл без отказов.
- Отрицательный прогон правил на исходном каркасе обнаружил 5 отсутствующих поведений (блок, перекат, сложности, отрицательный урон); после реализации эти проверки проходят.
- Интеграционные тесты выявили и воспроизвели пересечение зон NPC/костра, терявшее ожидаемую точку сохранения; зоны разнесены, проверки загрузки состояния проходят.
- Реальный рендер 1440×810: просмотрены главное меню, мир, диалог и настройки. Захват через tests/capture.gd, X11/Xvfb и software OpenGL llvmpipe; не замер производительности.
- macOS debug universal ZIP успешно экспортирован и проверен по CRC, наличию игрового пакета и arm64/x86_64 Mach-O. Финальный повтор импорта, 56 тестов, обеих сборок и запуска экспортированной Linux-игры завершился без ошибок.
- Оба игровых пакета проверены по оглавлению PCK v3: перевод и лицензия шрифта включены, внутренний сюжетный план, тесты и документация исключены.
- GitHub Actions настроен в .github/workflows/build.yml, но на GitHub ещё не выполнен.

## Доступ к GitHub

Существующий remote: RomanTheDev-cmd/my-game. Авторизованное git-чтение успешно; удалённый репозиторий был пустым. GitHub API отвечает Forbidden, веб-страница без API — 404. Это не принято за достоверное подтверждение private-статуса. Перед push требуется подтверждение пользователя, что рядом с названием стоит Private. Вопрос отправлен в чат. Не создавать новый публичный репозиторий и не заменять origin.

Локально создан initial main с правилами и исходным ТЗ; реализация находится в feature/first-playable. Далее — PR в main. Пока подтверждение приватности не получено, код остаётся локальным; API/создание PR отдельно не проверены. Публикация облачной среды не является отправкой проекта в GitHub.

## Ограничения

- Одна небольшая локация и один короткий квест; продолжительность 30–50 часов не достигнута и не измерена.
- Графика начальная, без полноценных анимаций, звука, динамического света и погоды.
- Нет полноценной магии, экипировки, навыков, крафта, дальнего боя, боссов, превращений, фракций, расписаний NPC, генерации подземелий и законченного сюжета.
- Противники преследуют напрямую, без обхода сложных препятствий. Переходов между локациями пока нет.
- Настройки оконного режима/сложности доступны, но отдельного постоянного файла настроек и переназначения клавиш пока нет.
- Физический геймпад, Retina, запуск на macOS, подпись/нотариализация, FPS и длительные сессии на Apple Silicon не проверены. macOS-архив неподписанный.
- Имя рабочее, товарные знаки не проверены.

Сюжетный план хранится отдельно в data/narrative; не раскрывать его игроку.
