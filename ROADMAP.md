# Дорожная карта

Общая цель — полная одиночная RPG по docs/SPECIFICATION.ru.md. Эта дорожная карта не является заявлением о готовности.

| Этап | Проверяемый результат | Статус |
|---|---|---|
| 1. Инфраструктура | Проект открывается; импорт/тесты/экспорт проходят; private GitHub, ветки и Actions работают | Private подтверждён пользователем; ветки отправлены; PR и результат Actions не подтверждены |
| 2. Основной цикл | Исследование → встреча → бой → награда → сохранение; смерть восстанавливает мир | Малый цикл с наградой реализован; нужны расширение и игровые испытания |
| 3. Мир | Несколько связанных авторских регионов, карта, переходы, навигация NPC, осмысленные подземелья | Шесть связанных локаций, карта, переходы, находки и навигация противников и перемещение NPC; большой мир и подземелья не выполнены |
| 4. Магия | Школы, затраты, прогрессия, ограничения, применение вне боя и тесты | Исцеление, световой заряд, замедляющий снаряд, защитный покров, человеческий обет и первая магия крови; полные школы, ритуалы и специализации не выполнены |

## Ближайшие задачи

1. Создать PR и проверить Actions, когда GitHub API станет доступен; не запрашивать повторное подтверждение Private.
2. Провести ручной прогон на Mac с клавиатурой/мышью; геймпад необязателен и у пользователя отсутствует.
3. Следующий блок: оставшиеся вампирские формы — летучая мышь/туман — через постепенное обучение и реальные исследовательские применения. Проверять узкие проходы, посадку/выход из формы, стены, затраты/солнце/диалоги и сохранения, не вводить бесконтрольный noclip. Продолжать тайные сообщества и специальные линии по внутренним материалам.
4. Затем продолжить кампанию и полноценные фракции; сохранить альтернативы и последствия уже встроенной линии. Добавлять специальные состояния и разнообразие заданий, развивать добровольные пути из ТЗ.
5. Развить визуал и звук: анимации, полноценные тайлы, тени и полноценный саундтрек; калибровать начальную библиотеку звуков и развивать начальные освещение и погоду; заменить раннюю графику по мере готовности.
6. Завершить внутренний сюжетный граф, затем постепенно создавать реальные сцены, диалоги и последствия без спойлеров в отчётах.

Цели 12–18 часов основного сюжета и 30–50 часов общего прохождения проверяются позднее тестированием, а не объёмом сгенерированного текста.
