# Дорожная карта

Общая цель — полная одиночная RPG по docs/SPECIFICATION.ru.md. Эта дорожная карта не является заявлением о готовности.

| Этап | Проверяемый результат | Статус |
|---|---|---|
| 1. Инфраструктура | Проект открывается; импорт/тесты/экспорт проходят; private GitHub, ветки и Actions работают | Локальные проверки; GitHub требует проверки доступа |
| 2. Основной цикл | Исследование → встреча → бой → награда → сохранение; смерть восстанавливает мир | Первый малый цикл реализован; нужны расширение и игровые испытания |
| 3. Мир | Несколько связанных авторских регионов, карта, переходы, навигация NPC, осмысленные подземелья | Не выполнен |
| 4. Магия | Школы, затраты, прогрессия, ограничения, применение вне боя и тесты | Только начальное исцеление |
| 5. Пути | Человек, добровольный вампиризм и ликантропия, формы, ограничения, сюжет возвращения, равноправное прохождение | Не выполнен; стартовый герой — человек |
| 6. Живой мир | Фракции, расписания, события с условиями и памятью, последствия решений | Не выполнен |
| 7. Сюжет | Внутренняя концепция, полный граф, альтернативы спасения, автоматическая проверка достижимости и тупиков | Внутренняя концепция; один проверочный квест |
| 8. Контент | Основной сюжет и побочные линии, предметы, ремёсла, навыки, разные противники и боссы | Не выполнен |
| 9. Баланс и оптимизация | Измеренный баланс путей и сложности, профилирование на Apple Silicon, длительные сессии | Не выполнен |
| 10. Релиз | Полный регрессионный прогон, проверенная macOS-сборка, релизные материалы, измерение продолжительности | Не выполнен |

## Ближайшие задачи

1. Подтвердить private-статус GitHub и отправить первую рабочую ветку; запустить Actions.
2. Провести ручной прогон на Mac с клавиатурой/мышью и геймпадом; исправить управление и коллизии.
3. Вынести переходы заданий из UI в самостоятельную проверяемую систему с графом условий.
4. Добавить вторую авторскую локацию и надёжный переход с сохранением состояния обеих.
5. Развить визуал: анимации, полноценные тайлы, освещение, звук и погоду; заменить ранние спрайты по мере готовности.
6. Развивать основной сюжет внутренними материалами, не раскрывая игроку секреты в отчётах.

Цели 12–18 часов основного сюжета и 30–50 часов общего прохождения проверяются позднее тестированием, а не объёмом сгенерированного текста.
