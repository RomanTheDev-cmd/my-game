# Дорожная карта

Общая цель — полная одиночная RPG по docs/SPECIFICATION.ru.md. Эта дорожная карта не является заявлением о готовности.

| Этап | Проверяемый результат | Статус |
|---|---|---|
| 1. Инфраструктура | Проект открывается; импорт/тесты/экспорт проходят; private GitHub, ветки и Actions работают | Private подтверждён пользователем; ветки отправлены; PR и результат Actions не подтверждены |
| 2. Основной цикл | Исследование → встреча → бой → награда → сохранение; смерть восстанавливает мир | Малый цикл с наградой реализован; нужны расширение и игровые испытания |
| 3. Мир | Несколько связанных авторских регионов, карта, переходы, навигация NPC, осмысленные подземелья | Три связанные локации, карта, переходы, находки и навигация противников и перемещение NPC; большой мир и подземелья не выполнены |
| 4. Магия | Школы, затраты, прогрессия, ограничения, применение вне боя и тесты | Исцеление и боевой световой заряд; остальные школы и ритуалы не выполнены |
| 5. Пути | Человек, добровольный вампиризм и ликантропия, формы, ограничения, сюжет возвращения, равноправное прохождение | Не выполнен; стартовый герой — человек |
| 6. Живой мир | Фракции, расписания, события с условиями и памятью, последствия решений | Базовые расписания трёх NPC, четыре контекстные встречи с памятью, доверие/цены, сутки и погода; полноценные фракции не выполнены |
| 7. Сюжет | Внутренняя концепция, полный граф, альтернативы спасения, автоматическая проверка достижимости и тупиков | Внутренняя концепция и сценарный граф с проверкой достижимости; два задания с проверкой альтернатив. Полная история не встроена |
| 8. Контент | Основной сюжет и побочные линии, предметы, ремёсла, навыки, разные противники и боссы | Начальные навыки, опыт, рецепт настоя, экипировка, торговля и три типа врагов; большой объём контента не выполнен |
| 9. Баланс и оптимизация | Измеренный баланс путей и сложности, профилирование на Apple Silicon, длительные сессии | Не выполнен |
| 10. Релиз | Полный регрессионный прогон, проверенная macOS-сборка, релизные материалы, измерение продолжительности | Не выполнен |

## Ближайшие задачи

1. Создать PR и проверить Actions, когда GitHub API станет доступен; не запрашивать повторное подтверждение Private.
2. Провести ручной прогон на Mac с клавиатурой/мышью; геймпад необязателен и у пользователя отсутствует.
3. Развить задания в полноценные линии с условиями репутации и последствиями; сюжетные сведения держать внутри проекта.
4. Развивать содержательные исследовательские локации и сюжетные сцены; добавить полноценные бои с боссами, специальные состояния и разнообразие заданий.
5. Развить визуал: анимации, полноценные тайлы, тени и звук; развивать начальные освещение и погоду; заменить раннюю графику по мере готовности.
6. Завершить внутренний сюжетный граф, затем постепенно создавать реальные сцены, диалоги и последствия без спойлеров в отчётах.

Цели 12–18 часов основного сюжета и 30–50 часов общего прохождения проверяются позднее тестированием, а не объёмом сгенерированного текста.
